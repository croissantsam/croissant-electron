# croissant-electron

A boilerplate for Electron, React, TypeScript, TanStack Router, Tailwind CSS, and shadcn/ui.

## Create a project

```bash
npx croissant-electron init my-electron-app
cd my-electron-app
pnpm install
pnpm dev
```

## Recommended IDE Setup

- [VSCode](https://code.visualstudio.com/)

## Project Setup

### Install

```bash
$ pnpm install
```

### Development

```bash
$ pnpm dev
```

### Build

```bash
# For windows
$ pnpm build:win

# For macOS
$ pnpm build:mac

# For Linux
$ pnpm build:linux
```
